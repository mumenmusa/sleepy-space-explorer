## Episode Structure Template

Each episode follows:

1. **Intro (2–3 min)** — greet the listener, set the scene softly
2. **Journey (20–25 min)** — slow, sensory-rich story
3. **Wind-down (3–5 min)** — breathing, warmth, drift into sleep
